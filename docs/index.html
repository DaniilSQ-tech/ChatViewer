Сравнивайте ответы моделей без переключения вкладок

ChatList — десктопное приложение для Windows. Отправьте запрос в выбранные модели через OpenRouter, отметьте лучшие ответы, сохраните историю и экспортируйте результат.

Мульти-модель

Один промт уходит сразу в несколько chat-моделей OpenRouter. Ответы — в общей таблице.

AI-ассистент

Улучшение и переформулировка промтов перед отправкой в основные модели.

История и экспорт

SQLite-база, поиск, сортировка, экспорт в Markdown и JSON.

Удобный интерфейс

PyQt6, светлая и тёмная тема, настраиваемый размер шрифта.

Быстрый старт

  1. Скачайте инсталлятор ChatViewer-Setup-*.exe с GitHub Releases.
  2. Установите ChatList и запустите из меню «Пуск».
  3. Получите ключ на openrouter.ai.
  4. Создайте файл .env.local в каталоге программы:
    OPENROUTER_API_KEY=sk-or-v1-ваш-ключ
  5. Введите промт, выберите модели на вкладке «Модели» и нажмите «Отправить».
